# 📊 Analisis Dashboard Penjualan Retail

## 📌 Gambaran Proyek
Proyek ini bertujuan untuk menganalisis data penjualan retail menggunakan dataset Superstore. Analisis ini mencakup tren penjualan, performa produk, kontribusi kategori, serta performa wilayah untuk menghasilkan insight bisnis yang dapat digunakan dalam pengambilan keputusan.

---

## 🛠️ Tools yang Digunakan
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

---

## 📈 Analisis yang Dilakukan
- Analisis tren penjualan bulanan
- Produk dengan penjualan tertinggi
- Performa penjualan berdasarkan wilayah
- Kontribusi kategori produk
- Segmentasi pelanggan

## 💡 Insight Bisnis

- Wilayah **West** memiliki penjualan tertinggi dibandingkan wilayah lainnya.
- Kategori **Technology** menjadi penyumbang pendapatan terbesar.
- Beberapa produk bernilai tinggi mendominasi total penjualan perusahaan.
- Wilayah **South** memiliki potensi untuk dikembangkan lebih lanjut.
- Penjualan tidak merata antar wilayah sehingga diperlukan strategi pemasaran yang lebih fokus.

---

## 🎯 Kesimpulan
Analisis ini membantu memahami pola penjualan perusahaan berdasarkan wilayah, produk, dan kategori. Hasilnya dapat digunakan untuk meningkatkan strategi pemasaran, pengelolaan stok, dan pengambilan keputusan bisnis berbasis data.
